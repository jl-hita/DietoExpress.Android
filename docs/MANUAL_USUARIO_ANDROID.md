# Manual de uso de DietoExpress para Android

**Destinatario:** pacientes que utilizan la aplicación móvil.  
**Objetivo:** explicar paso a paso cómo consultar la información, comunicarse con el profesional y registrar entrenamientos.  
**Importante:** las opciones visibles dependen de lo que haya habilitado o asignado tu profesional. Los nombres pueden variar ligeramente entre versiones.

## 1. Instalar, abrir y entrar

1. Instala DietoExpress desde Google Play o abre la versión de prueba que te haya facilitado el equipo.
2. Abre la aplicación y selecciona el acceso de paciente.
3. Introduce el email o teléfono asociado a tu ficha y sigue las instrucciones que aparecen en pantalla.
4. Si recibes un código de acceso, introdúcelo sin compartirlo con otras personas.
5. Si no puedes entrar, utiliza la opción para solicitar un enlace de acceso. Comprueba también que estás usando el email o teléfono que conoce tu profesional.
6. Para salir, utiliza la opción de cerrar sesión del perfil.

La sesión puede mantenerse entre aperturas. Si compartes el teléfono, cierra sesión y protege el bloqueo del dispositivo.

## 2. Navegación principal

La barra inferior permite cambiar entre las áreas disponibles:

- **Inicio:** resumen y accesos a las funciones principales.
- **Mi dieta:** consulta el plan alimentario activo.
- **Entrenamiento:** sesiones y registro del trabajo realizado, si tienes seguimiento deportivo activado.
- **Progreso:** revisiones y evolución disponibles.
- **Citas:** consulta, solicitud y gestión de citas.

El acceso al perfil se encuentra en la parte superior. Algunas opciones pueden aparecer como accesos directos desde Inicio y también dentro de su sección.

## 3. Consultar tu dieta

1. Entra en **Mi dieta**.
2. Selecciona el día que quieres consultar.
3. Abre cada comida para ver sus alimentos, cantidades y detalles.
4. Utiliza los valores de energía y macronutrientes por comida como referencia del plan.
5. Si tu profesional ha actualizado la dieta, vuelve a cargar la pantalla para consultar la versión más reciente.

La aplicación muestra la dieta asignada por tu profesional; no modifica por sí sola el plan. Si detectas un alimento que no puedes consumir, una alergia, una intolerancia o una cantidad que no entiendes, comunícalo antes de hacer cambios.

## 4. Lista de la compra

1. Abre **Lista de la compra** desde Inicio o desde el acceso correspondiente.
2. Revisa los productos y cantidades que aparecen.
3. Marca cada elemento al comprarlo.
4. Si necesitas recuperar la lista, vuelve a abrirla.

La lista se deriva de la dieta disponible. Si cambia el plan, actualiza la lista para evitar comprar cantidades de una versión anterior. Comprueba siempre el etiquetado real de los productos, especialmente ante alergias o intolerancias.

## 5. Entrenamientos y rutinas

Si tu profesional ha activado el seguimiento deportivo, entra en **Entrenamiento**. Verás las sesiones programadas y su información. Abre una sesión para consultar ejercicios, series, repeticiones, descansos e imágenes de técnica cuando estén disponibles.

### 5.1 Empezar una sesión

1. Abre la sesión que vas a realizar.
2. Pulsa **Iniciar entrenamiento** (o el control equivalente que aparezca).
3. Se abre el registro activo. La aplicación conserva un borrador local mientras introduces tus datos.
4. Completa cada ejercicio en el orden que prefieras, respetando las indicaciones de tu profesional.

### 5.2 Registrar cada serie

En cada ejercicio encontrarás una tabla con:

- **Serie:** número de la serie; las de calentamiento se distinguen de las series efectivas.
- **Kg:** carga utilizada. Escribe el peso realmente levantado.
- **Reps:** repeticiones realizadas.
- **RIR:** repeticiones que estimas que todavía podrías haber hecho al terminar la serie.
- **OK:** marca la casilla cuando hayas completado esa serie.

Marca una serie como completada solo después de realizarla. Si corriges un dato, edita el campo correspondiente antes de finalizar.

### 5.3 Acciones de cada ejercicio

Debajo de la tabla hay dos botones principales:

- **Cambiar ejercicio (izquierda):** abre el selector para sustituir ese ejercicio por otro disponible. La sustitución puede estar bloqueada si ya se han registrado series o si la sesión no admite cambios. Si está deshabilitado, no fuerces el cambio: termina el registro o consulta a tu profesional.
- **Más… (derecha):** abre las acciones adicionales:
  - **Añadir serie:** incorpora otra serie efectiva. La nueva fila propone valores iniciales a partir de la prescripción y de la última serie; comprueba y corrige los datos antes de marcarla.
  - **Añadir calentamiento:** incorpora una serie de calentamiento separada de las series efectivas.
  - **Quitar última serie:** elimina la última serie efectiva cuando hay más de una serie prescrita. Comprueba que no eliminas por error una serie que ya has realizado.

### 5.4 Descansos

Cuando el ejercicio tiene descanso recomendado, utiliza **Iniciar** para comenzar el temporizador. Puedes pausarlo, reanudarlo o detenerlo. Completar una serie efectiva también puede iniciar automáticamente el descanso configurado para ese ejercicio.

### 5.5 Valorar el ejercicio y explicar series no realizadas

- **Valorar ejercicio:** cuando hayas completado alguna serie, puedes indicar si el estímulo fue bajo, adecuado o alto; si hubo molestias articulares o tendinosas; y si el músculo seguía cargado al empezar. Son datos opcionales útiles para que el profesional revise la progresión.
- **¿Por qué no se completó?:** si quedan series sin marcar, selecciona el motivo que mejor describa lo ocurrido (por ejemplo, fatiga, carga excesiva, falta de tiempo, material, enfermedad o dolor). No marques como realizada una serie que no hiciste.

### 5.6 Finalizar y guardar

1. Revisa las series y los motivos de las que no hayas completado.
2. Indica el esfuerzo global de la sesión (RPE de 0 a 10).
3. Indica cómo te has recuperado y si has tenido molestias nuevas o que empeoran.
4. Si corresponde, describe las molestias y añade notas generales.
5. Pulsa **Finalizar y guardar entrenamiento**.

Si falta un dato obligatorio, la app te indicará qué debes completar. No cierres la sesión hasta que se haya guardado o quede claramente indicada como pendiente de sincronización.

### 5.7 Si pierdes la conexión

Los borradores de entrenamiento se guardan cifrados en el dispositivo. Puedes seguir preparando el registro sin conexión y finalizarlo cuando corresponda. El envío final puede quedar pendiente y se reintentará cuando vuelva la conexión. La pantalla de perfil permite revisar el estado de operaciones pendientes cuando esa opción está disponible.

No borres los datos de la aplicación ni cierres sesión para intentar resolver una sincronización pendiente: podrías perder el borrador local. Si un registro aparece pendiente durante mucho tiempo, conecta el teléfono a Internet y consulta con soporte antes de repetir el envío.

## 6. Revisiones y progreso

1. Entra en **Progreso**.
2. Consulta las revisiones disponibles y su evolución.
3. Si aparece un formulario de revisión semanal, completa los campos que se soliciten y revisa los datos antes de enviarlo.
4. Si la app indica que todavía no puedes enviar otra revisión, respeta el plazo que muestra.
5. Las gráficas necesitan mediciones registradas en distintos momentos; si solo existe una medición, puede que no haya una línea de evolución.

Un borrador puede permanecer guardado en el dispositivo. La revisión no se considera enviada hasta que la aplicación confirma el resultado del servidor.

## 7. Citas

1. Abre **Citas** para consultar tus próximas citas y el historial disponible.
2. Para solicitar una cita con tu profesional asignado, consulta los huecos disponibles y selecciona fecha y hora.
3. Si todavía no tienes profesional, puedes utilizar el directorio para buscar profesionales y seguir el flujo de solicitud de cita pública.
4. Revisa los datos y confirma la solicitud.
5. Para cancelar una cita futura, abre sus detalles y utiliza la acción de cancelar si está disponible.
6. La reprogramación directa puede no estar disponible: en ese caso, cancela si procede y solicita una nueva cita o contacta con tu profesional.

Una solicitud no siempre equivale a una cita confirmada. Comprueba el estado que muestra la aplicación y las comunicaciones recibidas.

## 8. Documentos

1. Abre **Documentos**.
2. Selecciona el documento asignado.
3. Descárgalo y ábrelo con el visor PDF disponible en el dispositivo.
4. Lee el contenido completo.
5. Si se solicita aceptación o firma explícita, utiliza el control correspondiente solo después de leerlo y estar de acuerdo.

Abrir o descargar un documento no significa necesariamente que lo hayas aceptado. La aceptación se registra mediante la acción específica de la aplicación.

## 9. Mensajes con tu profesional

1. Abre **Mensajes**.
2. Selecciona la conversación.
3. Escribe tu mensaje y envíalo.
4. Si no hay conexión, el mensaje puede quedar en cola para enviarse más tarde. Comprueba su estado antes de volver a escribirlo para evitar duplicados.
5. Utiliza mensajes para consultas no urgentes. No son un servicio de emergencias ni garantizan una respuesta inmediata.

## 10. Perfil, sincronización y privacidad

Desde el perfil puedes consultar los datos de cuenta y las opciones disponibles, revisar operaciones pendientes y solicitar sincronización cuando aparezca esa función. La app cifra la sesión y los datos locales sensibles. Aun así:

- Mantén Android actualizado y protege el teléfono con PIN, contraseña o biometría.
- No compartas códigos de acceso ni dejes la sesión abierta en un dispositivo ajeno.
- Si cambias de teléfono o de cuenta, asegúrate de que los datos pendientes se hayan sincronizado antes de desinstalar la aplicación.
- Para solicitar ayuda, indica el modelo de teléfono, la versión de Android y los pasos que has seguido; nunca envíes contraseñas, códigos ni capturas con datos de salud visibles.

## 11. Problemas habituales

| Problema | Qué hacer |
|---|---|
| No llega el código o enlace | Comprueba email/teléfono y carpeta de spam; solicita uno nuevo y contacta con tu profesional si persiste. |
| No aparece una dieta o entrenamiento | Comprueba que estás en la cuenta correcta y actualiza la pantalla; el profesional debe asignar el contenido. |
| No puedes cambiar un ejercicio | Puede haber series registradas o restricciones de fecha/estado. No se permite sustituirlo en todos los casos. |
| No se guardan los datos | Comprueba la conexión y el estado de sincronización. No repitas el envío si ya aparece pendiente. |
| No recibes notificaciones | Revisa los permisos de notificaciones de Android y el ahorro de batería. Abre la app para comprobar mensajes y citas. |
| No se abre un PDF | Instala o actualiza un visor PDF y vuelve a descargar el documento. |
| No puedes iniciar una videoconsulta | Comprueba conexión, permisos de cámara/micrófono y que la cita esté dentro de su ventana de acceso. |

## 12. Qué no sustituye la aplicación

DietoExpress es una herramienta de consulta, registro y comunicación. No sustituye las indicaciones del profesional, la comprobación de etiquetas alimentarias ni la atención sanitaria urgente. Ante síntomas graves o una urgencia, utiliza los servicios sanitarios adecuados.
